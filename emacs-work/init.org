* Preparation

This is a lightweight Emacs configuration for work environments. It
provides essential packages, a dark theme, basic C/C++ indentation,
and AI assistance via Ellama (connecting to a local llama-swap
fleet).

To use it, copy this file to your =~/.emacs.d/init.org=, then
bootstrap it with the following =~/.emacs.d/init.el=:

#+begin_src emacs-lisp :tangle no
;; Bootstrap: tangle init.org on first load
(require 'org)
(org-babel-tangle-file
 (expand-file-name "init.org" user-emacs-directory))
(load (expand-file-name "init.el" user-emacs-directory))
#+end_src

** Bootstrapping

Tangle and compile this file on save.

#+begin_src emacs-lisp
;;;; -*- lexical-binding: t -*-

(defun tangle-init ()
  "If the current buffer is 'init.org' the code-blocks are
tangled, and the tangled file is compiled."
  (when (equal (buffer-file-name)
               (expand-file-name (concat user-emacs-directory "init.org")))
    (let ((prog-mode-hook nil))
      (org-babel-tangle))))

(add-hook 'after-save-hook 'tangle-init)
#+end_src

  (unless (file-exists-p bootstrap-file)

** Ellama

AI assistant using the local llama-swap fleet on Navi. Cloud models
tagged with =:cloud= are proxied through the Ollama instance on Navi,
which must be reachable over LAN or Tailscale.

Fleet snapshot (October 2026). Dual-mode models expose a =:think=
variant with reasoning enabled; run =llama-swap-cli list= on Navi for
the live view:

- =ornith-1.5-35b-heretic= (35B MoE A3B, vision + thinking + tools,
  APEX I-Compact, 200K ctx — flagship)
- =qwen3.6-35b-a3b-heretic= (34.7B MoE A3B, vision + thinking + tools,
  131K ctx)
- =qwen3-coder-30b= / =qwen3-coder-30b-fast= (30B MoE coder, tools, no
  thinking, 131K ctx)
- =laguna-xs-2.1= (33B dense, thinking + tools, 131K ctx)
- =k2-horizon-36b= (36B, thinking + tools, 131K ctx)
- =neohorse-1-4b= (4.2B, thinking + tools, 128K ctx)
- =qwen3.5-4b= (4.2B, thinking + tools, 128K ctx)
- =lfm2.5-2.6b= (2.7B, thinking + tools, 128K ctx)
- =translategemma-4b= (translation specialist)

Also in the fleet, but not in the picker (specialists): =glm-ocr=
(vision/OCR), =lfm2.5-vl-3b= (vision), =minicpm5-2b=, =nanbeige4.2-3b=,
=twil-lm3-pro= (logic-formal specialist), =laya= / =julia-1= (decision

(=lfm2.5-embedding-350m=, =lfm2.5-colbert-350m=, =nemotron-3-embed-1b=)
and the Portal 2 personality cores.
