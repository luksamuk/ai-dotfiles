* Sobre

Este repositório contém configurações /dotfiles/ para diversas ferramentas de IA — agentes de código, CLIs, geração local de mídia, serviços Docker e a frota de modelos — tudo versionado em um só lugar para facilitar sincronização entre máquinas.

** Máquinas

| Nome      | O que é                              | Papel                                              |
|-----------+--------------------------------------+----------------------------------------------------|
| Navi      | notebook Dell G15, i7-13650HX, RTX 3050 6GB | estação principal: geração local, frota, agentes |
| Sisyphus  | Raspberry Pi 4                       | serviços sempre-ligados: Forgejo, backups, dashboard |

** O que não está aqui

Pesos de modelo (GGUF, safetensors, checkpoints) **não** são versionados: são grandes e reconstruíveis a partir de manifestos. Cada lane que depende disso documenta como reinstalar (ver seção H3 e =scripts/install/=).

* h3 — MiniMax H3 (vídeo com áudio)

Geração local de vídeo com áudio sincronizado (MiniMax H3) via Wan2GP, na RTX 3050 6GB.

- **Wrapper**: =h3/h3= (instalado em =~/.local/bin/h3=)
- **Catálogo**: =h3/build_h3_catalog.py= gera o catálogo a partir do disco; =h3/lora_selector.py= escolhe as LoRAs
- **Auxiliares de runtime**: =h3/scripts/= — 6 arquivos dos quais o wrapper depende
- **Patches**: =wan2gp-patches/arquivos/models/minimax_h3/prompt_enhancer.py= (system prompts do enhance)

** Lane padrão

#+BEGIN_SRC bash
h3 "descrição da cena" --enhance             # 1344x768, turbo 8 steps, ~13 min
h3 "..." --nsfw --enhance                    # modo adulto
h3 "..." --frames 362                        # 15,08s (teto de passe único)
h3 "..." --steps 12                          # sobrescreve o turbo
#+END_SRC

| Item | Valor |
|---|---|
| Resolução default | 1344x768 (treino nativo) |
| Steps | 8 (turbo resized rank_21 @ 0,5) |
| Teto de passe único | 362 frames = 15,08s |
| Saída | MKV + FFV1 + FLAC (lossless) |
| Aceleradores | turbo rank_21 (FL2VA) — Ref2VA não tem |

** Seleção de LoRAs

O wrapper tem duas autoridades possíveis, escolhidas por =lora_selector= no
=~/.local/share/fleet/enhance-models.yaml= (ou =--lora-selector=):

- =decision= (default): o LLM escreve o prompt, o **seletor** escolhe as LoRAs
- =llm=: o LLM escreve o prompt **e** escolhe (modo antigo, mantido para comparar)

No modo =decision= o seletor aplica: gate de ato (pergunta =choice= ao modelo),
eixo de papel (capacity 1 por função), pins (AIO em cena de ato, identidade por nome citado).

** Pesos não são versionados

Os ~59 GiB de pesos (2 bases + text encoder + VAEs + predictors + turbo + LoRAs) saem e
voltam por manifesto:

#+BEGIN_SRC bash
bash scripts/install/h3-restore.sh          # baixa tudo, confere sha256, recria symlinks
bash scripts/install/h3-uninstall-pesos.sh  # dry-run; --exec para remover
#+END_SRC

Detalhes, pegadinhas e o que permanece: =wan2gp-patches/H3-RESTORE-NOTES.md=.

** Dados de curadoria (repo separado, privado)

O catálogo tem descrições de conteúdo adulto (o texto que o classificador lê). Isso fica
em reposítório **privado e cifrado**, não aqui:

- =github.com/luksamuk/h3-data= (privado, GPG com a chave do Keybase)
- contém =catalog_cur.py=, manifestos de LoRAs e os catálogos gerados

A curadoria local vive em =~/.local/share/h3/catalog_cur.py= (o builder importa de lá).

* Linear MCP — Issue Tracking em Todos os Harnesses

O [[https://linear.app/docs/mcp][Linear MCP server]] está configurado em todos os harnesses que suportam MCP, exceto no Pi (que usa plugin nativo) e no Hermes (que tem Kanban embutido).

O Linear MCP server (=https://mcp.linear.app/mcp=) usa *OAuth 2.1* com Dynamic Client Registration. Nenhuma chave de API é versionada nos arquivos de config — a autenticação é feita via browser na primeira execução de cada harness.
